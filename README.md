# Federico Rodríguez Torres — Portfolio

Personal portfolio of **Federico Rodríguez Torres**, **AI / GenAI Engineer**.

🔗 **Live:** [federico-rodriguez-torres.netlify.app](https://federico-rodriguez-torres.netlify.app)

I design AI agents and bring them to production — LLMs, RAG and automation that solve real
business problems, end to end.

## Tech
Static, self-contained single-page site — **HTML + CSS + vanilla JS** (no build step). Responsive,
dark theme, SEO/OpenGraph tags, scroll-reveal animations. Fonts via Google Fonts (Inter + JetBrains Mono).

## Structure
```
index.html   → the whole site (styles + markup + script inline)
cv.pdf       → downloadable CV (linked from the site)
```

## Run locally
Just open `index.html` in a browser — there is nothing to build or install.

## Deploy
- **Netlify:** drag the folder (or a zip of it) into Netlify Drop, or connect this repo for
  continuous deploy. `index.html` is the entry point.
- **GitHub Pages:** enable Pages on the `main` branch (root).
